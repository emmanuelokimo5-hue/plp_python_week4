# PLP Python Week 4

This repository contains my Week 4 Python assignment on functions, parameters, return values, and default parameters.

- `welcome.py` - Contains a welcome() function that creates personalized PLP greetings.
- `toolbox.py` - Contains double(), is_pass(), and greet() functions for practicing Python functions.

The hardest function to write was `greet()` because it uses a default parameter for the greeting. I had to understand how the function uses "Hello" when no greeting is provided and uses a different greeting when one is given.
